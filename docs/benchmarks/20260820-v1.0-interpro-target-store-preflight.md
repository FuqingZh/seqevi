## Decision

InterPro/Pfam Fresh read-only Preflight v3 is accepted under the scoped S0/S1 audit in
the [successor plan](../implementation-plan/20260820-v1.0-interpro-target-store-successor-implementation-plan.md).
Production remained active. Across the exact target union, all 38,565 keys
were `missing -> missing`; every sanity, C1 and C2 set therefore selects the
all-missing branch. No annotation or Store/CAS/resource mutation occurred.

V3 closes the exact-head review gaps with the official PyPI wheel and matching
`v0.3.1` source identity, an operator-approved 256 GiB memory reserve, a
16,140-second representative production-growth window scaled to the authorized
sanity cutoff with a 2x factor, an identity-bearing PostgreSQL plus referenced
CAS recovery artifact, a redacted live deployment mapping, and per-invocation
multi-batch watchdogs. Production was not paused.

This record does not authorize or report sanity execution. The corrected plan
head must first pass the canonical gate, be pushed, and receive clean
exact-current-head review. Target key state, intersecting claims and capacity
must then be refreshed immediately before mutation.
