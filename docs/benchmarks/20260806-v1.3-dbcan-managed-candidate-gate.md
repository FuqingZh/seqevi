## Decision

The GHCR publication record remains accepted distribution evidence. The real
scientific gate passed with a Linux/amd64 local candidate built from the exact
published release inputs. The candidate was addressed by its immutable local
image ID and did not masquerade as the public digest. Public setup, profiles,
and the bundled digest-pinned GHCR reference were not changed.

## Follow-up

Keep the current release recipe unchanged. For the next image recipe, evaluate
a pinned `uv` release with requirements/lock compatibility,
`--require-hashes`, and BuildKit cache mounts. Do not adopt PDM for the two
isolated runtime environments, and do not turn this evaluation into a public
image override or profile behavior change.
