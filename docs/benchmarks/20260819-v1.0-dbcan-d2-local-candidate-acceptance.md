# dbCAN D2 Local-Candidate Acceptance

> Status: accepted
> Date: 2026-08-19
> Release: SeqEvi 0.3.1

## Decision

D2 is accepted under the approved local-candidate recovery addendum. Public
GHCR acquisition remains transport evidence rather than a scientific
prerequisite. The public dbCAN digest and ordinary managed profile remained
absent; no production CLI, kit, profile or OCI contract was overridden.

The accepted candidate was rebuilt from published SeqEvi `0.3.1` source
revision `da55c14d95ef61140d3fa9c047df333aaea8798c` with the release Dockerfile,
both hash-locked requirements files, a wheel independently built from that
revision and all five SHA-verified `inputs.json` artifacts. Its sole execution
identity is immutable local image ID
`sha256:75b74528663f7b3bc06a48292c13a488447c5f32581fc461abdc242bf9321e13`.

## Base Transport And Provenance

Two Docker Hub metadata requests for the pinned base had previously reset. A
read-only Buildx inspection of
`public.ecr.aws/docker/library/python@sha256:ac76900038d8606cc99b413d4ede77bc7152f1e42b94cf5d50d4b80a999652fe`
returned that exact OCI manifest digest. The release build used ECR only as a
transport endpoint. The Dockerfile and final labels retain base name
`docker.io/library/python:3.13.11-slim-bookworm` and the same digest.

The first ECR build stopped on an incomplete upstream artifact read before the
SHA gate accepted it. After a 60-second backoff, one identical bounded retry
completed every SHA verification and release self-check. Final label and
content readback recorded Linux/amd64, SeqEvi 0.3.1, dbCAN 5.2.9, DIAMOND
2.1.15, revision `da55c14...`, runtime user `65532:65532`, the expected
entrypoint and no bundled annotation database.

The wheel built from the independent `da55c14...` source archive has SHA-256
`173d9da39b891d53a9ee60cac543d049da0f58aa7402a5c6db24c93e52388fb1`,
and is byte-identical to the released 0.3.1 wheel. The release Dockerfile,
SeqEvi lock, dbCAN lock and `inputs.json` SHA-256 values are respectively
`28ecc45219cd83caec72b1a73707f76d3893d62da753ab5152228bc578bf6c05`,
`193f2b4f692b5f41f3e6d6aaa4bd20036261612de800ed1ec71aff5b5542f669`,
