# dbCAN D2 Local-Candidate Acceptance

> Status: accepted
> Date: 2026-08-19

## Decision

D2 is accepted under the approved local-candidate recovery addendum. Public
GHCR acquisition remains transport evidence rather than a scientific
prerequisite. The public dbCAN digest and ordinary managed profile remained
absent; no production CLI, kit, profile or OCI contract was overridden.

The accepted candidate was rebuilt from published SeqEvi `0.3.1` source
revision `da55c14d95ef61140d3fa9c047df333aaea8798c` with the release Dockerfile,
both hash-locked requirements files, a wheel independently built from that
revision and all five SHA-verified `inputs.json` artifacts. Its sole execution
identity is immutable local image ID
`sha256:75b74528663f7b3bc06a48292c13a488447c5f32581fc461abdc242bf9321e13`.

## Retained D1 Workload And Capacity Gate

The accepted D1 sanitized evidence manifest is identified by manifest-file
SHA-256 `ee7e44168da6c5fd746815c35f496797d916c1c3a4055f4770fd1dcc78ac5b1f`.
Its isolated evidence root remains outside the repository. The D4 sizing input
is 2,729 unique keys, 828,607 residues, length 11..3,275, nearest-rank
p50/p90/p95/p99 262/542/684/1,082, and sorted-length-vector SHA-256
`6710b235958bdea47a0cd9cf8ad8cc7f94003994c2e5624e247f79ef83a5593b`.
The fixed 50 is 21,976 residues, length 169..1,060, and is an exact subset.

D4 has a finite 86,400-second OCI timeout; D3 has 7,200 seconds, setup smoke
120 seconds, and Docker create/remove 30 seconds. Minimum final reserves are
256 GiB available RAM, 2 TiB home/Docker/result space, 128 GiB root/tmp and
100 TiB Ceph. A pre-run 1-minute load above 96, any reserve breach, unhealthy
Store, nonzero coordination rows or invocation-owned container delta stops the
lane. The accepted host snapshot recorded 192 logical CPUs/96 physical cores,
503 GiB total RAM with about 432.4 GiB available, about 274 GiB root, 3.68 TiB
home/Docker/result and 194 TiB Ceph available. D4 must refresh these values and
measure workload-specific CPU, RSS, scratch and Ceph I/O; the retained snapshot
does not waive any live stop gate.

Final readback found both Store endpoints healthy at revision
`0004_claim_sessions`; 53,720 sequence rows, 53,721 evidence rows, 33 artifact
rows, 20,542,641 artifact bytes and zero coordination rows. All 33 CAS files
revalidated with no mismatch, extra or temporary file. Resource metadata,
