because of its daemon-side registry transport/authentication path. The public

does not substitute for the real caller-mounted smoke.

the pinned kit identity for strict profile parsing and read-only setup
planning. Do not mark `seqevi setup` apply, OCI annotation delegation or the
public managed release as complete until the remaining caller smoke is
