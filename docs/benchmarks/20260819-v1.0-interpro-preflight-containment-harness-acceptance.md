# InterPro Preflight Containment Harness Acceptance

Version: v1.0
Date: 2026-08-19
Status: accepted harness prerequisite; InterPro read-only Preflight next

## Outcome

The repository-owned eggNOG/InterPro acceptance launch boundary now requires
two distinct finite deadlines: an internal adapter timeout passed to
`seqevi annotate --timeout-seconds` and a strictly longer external watchdog.
The benchmark-only wrapper delegates process ownership to the existing product
`ToolRunner`; it does not duplicate or weaken that contract. `ToolRunner`
launches an argument array without a shell in a dedicated session/process
group, keeps stdout and stderr in independent roots, sends TERM, waits a fixed
grace no longer than 60 seconds, sends KILL, waits/reaps the leader, and returns
only after repeated `/proc` readback proves no live group member and no
ambiguous process state.

The frozen eggNOG C2 harness values are a 21,600-second internal timeout,
21,660-second external watchdog, and 30-second termination grace. These values
are harness safety configuration only and do not alter accepted scientific
inputs, identities, parameters, results or Store evidence. InterPro must freeze
its own internal and longer watchdog values during read-only Preflight before
any annotation is authorized.

No annotation, Store/CAS mutation, image pull, or eggNOG C1/C2 rerun occurred
for this acceptance.

## Focused Failure-Path Evidence

The focused command was:

```bash
pdm run pytest tests/test_acceptance_containment.py \
  tests/test_acceptance_harnesses.py tests/test_runner.py -q
```

It passed 74 tests. The new tests launch real Python processes rather than
accepting normal-exit scans as timeout evidence:

- a hanging leader and TERM-resistant descendant exceed the external
  watchdog; observed signals include TERM and KILL, both TERM handlers run,
  the leader is reaped, and `/proc` readback finds no live member in the owned
  process group;
- a leader that exits before its TERM-resistant descendant is still fenced,
  killed/reaped as applicable, and leaves the owned group empty; and
- non-finite/non-positive deadlines, a watchdog not longer than the internal
  timeout, grace above 60 seconds, and CLI/internal-timeout mismatch all fail
  closed.
