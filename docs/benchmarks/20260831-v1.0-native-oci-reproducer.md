## Scope And Preparation

This document preserves the two exact passing scripts for the
[qualification report](20260831-v1.0-native-oci-qualification.md).
They mutate only new disposable resources. Native tests require Linux/amd64,
Python 3.13, OpenSSL, htpasswd, and an authorized user systemd manager.
The managed canary additionally requires Docker and the exact locally available
image identified below. No dependency installation, production restart,
scientific annotation, or host credential reuse is part of these scripts.

Allow 4 GiB scratch for one native run; serialize large runs. The recorded
execution retained two failed attempts until evidence extraction, producing
approximately 7 GiB peak aggregate scratch usage. Do not place any script in
a pre-existing Store directory. Prepare a fresh task root and acquire only
these official assets:

```bash
probe_root=$(mktemp -d /tmp/seqevi-oci-unit0-XXXXXXXX)
curl --fail --location --output "$probe_root/zot-linux-amd64-minimal" \
  https://github.com/project-zot/zot/releases/download/v2.1.20/zot-linux-amd64-minimal
curl --fail --location --output "$probe_root/oras_1.3.4_linux_amd64.tar.gz" \
  https://github.com/oras-project/oras/releases/download/v1.3.4/oras_1.3.4_linux_amd64.tar.gz
sha256sum "$probe_root/zot-linux-amd64-minimal" "$probe_root/oras_1.3.4_linux_amd64.tar.gz"
```

Compare both hashes with the report's release identities before extracting or
executing; stop on mismatch. Extract only the ORAS binary into that task root,
make both binaries executable, and save the native Python block below exactly
as `probe.py`, ending in one newline. Its SHA-256 must be
`28931f28ffb63b38d0d87cbf8d4a3f74cee48835c8fd9c9889eebab06f36e489`.
The script also verifies the executable's hash against the checked archive
member and asserts native versions.

```bash
tar -xzf "$probe_root/oras_1.3.4_linux_amd64.tar.gz" -C "$probe_root" oras
chmod u+x "$probe_root/oras" "$probe_root/zot-linux-amd64-minimal"
sha256sum "$probe_root/probe.py"
systemd-run --user --unit="seqevi-oci-$(basename "$probe_root")" \
  --collect --wait --pipe --property=KillMode=control-group \
  --property=MemoryMax=2G --property=CPUQuota=200% \
  --property=TasksMax=128 --property=RuntimeMaxSec=600 \
  --property="WorkingDirectory=$probe_root" python3.13 "$probe_root/probe.py"
```

Read `result.json`, `http-events.json`, and both Registry logs. Exit zero
plus `qualification_core: pass` is the native verdict; a script exception
is not a pass. No partial result from a previous attempt substitutes for it.
The script uses test-only credentials; do not replace them with real secrets.
Do not publish full Registry debug logs with reusable upload locations or
credentials. Preserve sanitized outcomes rather than command transcripts.

def digest(path: Path) -> str:
    with path.open('rb') as stream:
        return hashlib.file_digest(stream, 'sha256').hexdigest()


def save(name: str, value: object) -> None:
    with LOCK:
        RESULT['cases'][name] = value
    print(json.dumps({name: value}), flush=True)


def stop(child: subprocess.Popen) -> str:
    mode = 'already-exited'
    if child.poll() is None:
        mode = 'sigterm'
        os.killpg(child.pid, signal.SIGTERM)
        try:
            child.wait(timeout=10)
        except subprocess.TimeoutExpired:
            mode = 'sigkill'
            os.killpg(child.pid, signal.SIGKILL)
            child.wait(timeout=5)
    try:
        os.killpg(child.pid, 0)
    except ProcessLookupError:
        RESULT['cleanup'].append({'pid': child.pid, 'group_empty': True})
    else:
        raise RuntimeError(f'child process group remains: {child.pid}')
    return mode


def run(args: list[str | Path], *, timeout=90, expect=0, input_data=None):
    command = [str(item) for item in args]
    started = time.monotonic()
    child = subprocess.Popen(command, cwd=ROOT, env=ENV, start_new_session=True,
                             stdin=subprocess.PIPE if input_data is not None else subprocess.DEVNULL,
                             stdout=subprocess.PIPE, stderr=subprocess.PIPE)
    CHILDREN.append(child)
    timed_out = False
    try:
        out, err = child.communicate(input_data, timeout=timeout)
    except subprocess.TimeoutExpired:
        timed_out = True
        stop(child)
        out, err = child.communicate()
    recorded_command = command[:-1] + ['<disposable-fixture-redacted>'] if command[0] == 'htpasswd' else command
    record = {'argv': recorded_command, 'rc': child.returncode, 'timed_out': timed_out,
              'seconds': round(time.monotonic() - started, 3),
              'stdout': out.decode(errors='replace')[-6000:],
              'stderr': err.decode(errors='replace')[-6000:]}
    with LOCK:
        RESULT['commands'].append(record)
    assert not timed_out, record
    if expect is not None:
        assert child.returncode == expect, record
    return record


def free_port():
    with socket.socket() as sock:

def flags(tls=False, anon=False):
    result = ['--registry-config', str(ANON if anon or not tls else AUTH)]
    return result + (['--ca-file', str(ROOT/'tls.crt')] if tls else ['--plain-http'])


def make_manifest(path: Path, media_type='application/octet-stream'):
    body = {'schemaVersion': 2, 'mediaType': MANIFEST_TYPE, 'artifactType': ARTIFACT_TYPE,
            'config': {'mediaType': 'application/vnd.oci.empty.v1+json',
                       'digest': 'sha256:'+digest(EMPTY), 'size': 2},
            'layers': [{'mediaType': media_type,
                        'digest': 'sha256:'+digest(path), 'size': path.stat().st_size,
                        'annotations': {'org.opencontainers.image.title': 'artifact.bin'}}]}
    encoded = json.dumps(body, sort_keys=True, separators=(',', ':')).encode()
    target = ROOT / (hashlib.sha256(encoded).hexdigest() + '.manifest.json')
    if target.exists():
        assert target.read_bytes() == encoded
    else:
        target.write_bytes(encoded)
    return target


def publish(repository: str, path: Path, *, tls=False, media_type='application/octet-stream'):
    for item in (EMPTY, path):
        run([ORAS, 'blob', 'push', *flags(tls), '--descriptor', repository, item])
    manifest = make_manifest(path, media_type)
    reference = repository + ':sha256-' + digest(manifest)
    run([ORAS, 'manifest', 'push', *flags(tls), '--descriptor', reference, manifest])
    return reference, 'sha256:'+digest(manifest)


def pull(reference, output, expected, tls=False):
    run([ORAS, 'pull', *flags(tls), '--concurrency', '1', '--output', output, reference])
    assert digest(Path(output)/'artifact.bin') == digest(expected)


class FaultProxy(http.server.ThreadingHTTPServer):
    daemon_threads = True

    def __init__(self, backend_port):
        super().__init__(('127.0.0.1', 0), ProxyHandler)
        self.backend_port = backend_port
        self.mode = 'normal'
        self.events = []
        self.trigger = threading.Event()
        self.worker = threading.Thread(target=self.serve_forever, daemon=True)
        self.worker.start()


class ProxyHandler(http.server.BaseHTTPRequestHandler):
    protocol_version = 'HTTP/1.1'

    def log_message(self, *args):
        pass

    def handle_one_request(self):
        self.connection.settimeout(5)
        try:
            super().handle_one_request()
        except (OSError, http.client.HTTPException):
            self.close_connection = True

    def relay(self):
        proxy = self.server
        mode = proxy.mode
        length = int(self.headers.get('Content-Length', 0))
        is_blob_put = self.command == 'PUT' and '/blobs/uploads/' in self.path
        is_manifest = self.command == 'PUT' and '/manifests/' in self.path
        upstream = http.client.HTTPConnection('127.0.0.1', proxy.backend_port, timeout=5)
        try:
            upstream.putrequest(self.command, self.path)
            for key, value in self.headers.items():
                if key.lower() not in ('host', 'connection', 'expect'):
                    upstream.putheader(key, value)
            upstream.endheaders()
            remaining = length
            sent = 0
            while remaining:
                data = self.rfile.read(min(65536, remaining))
                if not data:
                    break
                upstream.send(data)
                sent += len(data)
                remaining -= len(data)
                if is_blob_put and mode in ('drop-upload', 'slow-upload'):
                    proxy.trigger.set()
                    if mode == 'drop-upload':
                        proxy.events.append({'fault': mode, 'forwarded_bytes': sent})
                        self.close_connection = True
                        self.connection.shutdown(socket.SHUT_RDWR)
                        return
                    time.sleep(0.01)
            if remaining:
                return
            response = upstream.getresponse()
            event = {'method': self.command, 'path': self.path.split('?')[0],
                     'sent_bytes': sent, 'status': response.status}
            proxy.events.append(event)
            if is_manifest and mode == 'lose-manifest-response' and response.status == 201:
                response.read()
                proxy.trigger.set()
                proxy.events.append({'fault': mode, 'upstream_status': 201})
                self.close_connection = True
                self.connection.shutdown(socket.SHUT_RDWR)
                return
            self.send_response(response.status)
            for key, value in response.getheaders():
                if key.lower() in ('connection', 'transfer-encoding'):
                    continue
                if key.lower() == 'location':
                    value = value.replace(f'127.0.0.1:{proxy.backend_port}',
                                          f'127.0.0.1:{proxy.server_port}')
                self.send_header(key, value)
            self.send_header('Connection', 'close')
            self.end_headers()
            if self.command != 'HEAD':
                while data := response.read(65536):
                    self.wfile.write(data)
            self.close_connection = True
        finally:
            upstream.close()

    do_GET = do_HEAD = do_POST = do_PUT = do_PATCH = do_DELETE = relay

## Managed Interface Canary

This is deliberately not a new-image build. The exact local SeqEvi image ID is
embedded in the script and must already exist; `--pull=never` is enforced.
An equivalent image with different identity requires a separately recorded
run, not silent substitution or a claim that package distribution passed.
The inner executable is a verified read-only bind. No host port is published;
all containers are on a disposable internal bridge.

Create a fresh `/tmp/seqevi-oci-managed-XXXXXXXX` root. Copy only the verified
ORAS and zot binaries into it. Save the block below as `probe.py`, with one
final newline, and check SHA-256:
`04e7d7aee21a7c4b9663ee7ad109ff1bb9ca26328816a2a6c9578d9e0eb02efb`.
Run under a uniquely named user unit with a 300-second runtime ceiling,
512 MiB memory, 100% CPU, 64 tasks and `KillMode=control-group`, as above.
Containers have their own resource limits because Docker daemon descendants
are not contained by the launching user unit.

The script explicitly removes its named containers/network and reads absence
back. If the script is externally killed, a finished user unit alone is not
Docker cleanup proof: inspect only its exact names and remove remaining
probe-owned resources before claiming completion. Do not use global prune.
