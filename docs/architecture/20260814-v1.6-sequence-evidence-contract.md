# Sequence Evidence Contract

Version: v1.6

Date: 2026-08-14

Status: approved target architecture

Supersedes: [v1.5](20260813-v1.5-sequence-evidence-contract.md)

SeqEvi retains the v1.5 immutable evidence, invocation-scoped ClaimSession,
bounded authority-readback, generation-fence, locking, synchronous public Store
API, compatibility, and actively cancellable network-operation contracts.

The internal `claim-session-v1` request and response boundary additionally
enforces these fixed protocol limits:

- an empty PostgreSQL acquire is a write-free no-op that returns an empty result
  and creates no acquire receipt;
- receipt-capacity admission retry snapshots the current renewal deadline while
  holding the same lock that protects renewed authority;
- an authority check accepts at most 1,000 exact claims; and
- open and renew responses report at most 120 seconds of remaining lease and at
  most 90 seconds to the renewal deadline.

These limits add no public API, route, configuration, or user-facing timing
knob. They preserve the released Store and wire compatibility described by
v1.5. HTTP transport ownership, PostgreSQL maintenance connection acquisition,
and external-tool cancellation remain governed by their separately assigned
delivery units.
