# Sequence Evidence Contract

Version: v1.4

Date: 2026-08-13

Status: approved target architecture; activation pending

Supersedes: [v1.3](20260812-v1.3-sequence-evidence-contract.md)

SeqEvi retains the v1.3 immutable `EvidenceKey`, artifact, evidence, lookup,
fetch, legacy commit, and invocation-scoped ClaimSession contracts. Each
claim-capable annotation opens exactly one opaque session authority. Exact-key
claims retain durable, monotonically increasing generation fences.

The internal protocol is capability-gated at
`/v1/internal/claim-sessions/{capabilities,open,renew,acquire,authority,finalize,close}`.
The authority route reads back only the bounded requested `EvidenceKey` tuples
for the exact session, accepts at most 1,000 claims, and requires every
requested generation to match. Its
database work therefore scales with the request rather than all claims retained
by a long-lived session. Acquire hashing, idempotency, fallback, and all v0.2.0
source and wire compatibility remain as specified by v1.3.

PostgreSQL takes deduplicated signed advisory IDs in numeric order before stable
session-row locks. SQLite provides equivalent authority through database
serialization. Durable generation high-water tombstones are never swept.
