# SeqEvi v1.1 Adapter Result Contract

> Status: historical; archived; see `docs/README.md` for current authority
> Contract version: 1.1
> Date: 2026-08-04
> Supersedes: result-output portions of `20260720-v1.0-adapter-contract.md`

## Scope

The v1.0 adapter identity, runtime boundary, resource lock, semantic
parameters, and Store `EvidenceKey` remain normative. This version adds the
delivery boundary for an accepted adapter result. The complete relation layout
is defined by the [result consumption contract](../../architecture/20260804-v1.1-result-consumption-contract.md).

## Adapter-Native Evidence

An adapter still returns one normalized Parquet artifact to the Store. The
artifact keeps the adapter's native row grain and starts with `SequenceID`.
The DuckDB writer copies that artifact into `main.evidence` for the current
invocation; it does not merge fields from another adapter or rename fields to
a universal ontology.

The result schema identity is an upstream-facing label:

| Adapter | ResultSchemaID | Row grain |
| --- | --- | --- |
| eggNOG-mapper | `eggnog-mapper/2` | eggNOG primary annotation row |
| InterProScan Pfam | `interproscan-pfam/5` | native Pfam domain match row |
| dbCAN CAZyme | `dbcan-cazyme/5` | normalized CAZyme method/hit row |

`ResultSchemaID` is not a replacement for `AdapterContractVersion`. The latter
continues to protect parsing, linkage, and cache semantics; the former tells a
consumer which adapter-native public columns and row grain to expect.

## Hit And No-Hit Accounting

The adapter must account for every requested canonical sequence exactly once as
`hit` or `no_hit`. Hit rows enter `main.evidence`; no-hit sequences enter
`main.sequence_map` with null adapter fields in the `main.annotations` view and
are deduplicated in `main.no_hits`.

One-to-many evidence is preserved. A Pfam sequence with three domain matches
produces three evidence rows and three annotation rows for each input record
that maps to that sequence. A consumer seeking one row per input protein must
aggregate explicitly; SeqEvi does not silently collapse domains.

## Provenance

Every result records the resolved adapter name, internal contract version,
upstream tool/version, `ToolRuntimeDigest`, `ResourceID`, semantic parameters,
input digest, and creation time in `_seqevi.metadata`. Runtime and resource
paths are not scientific identity and are not copied into the public evidence
schema.

## Acceptance Boundary

Adapter tests continue to validate native output parity, malformed output,
hit/no-hit accounting, deterministic normalization, and local/shared Store
parity. The new result gate additionally verifies that current eggNOG and
InterPro fixtures preserve schema, values, row grain, provenance, and no-hit
visibility when materialized into the DuckDB relations.
