This addendum supersedes only issue #33 execution details after exact-head
review exhausted the prior local-fix budget. Delivery remains one independently
reviewable PR because resolver ownership, artifact-reader ownership,
logical-operation draining, and Store close jointly establish one transport
lifecycle invariant. Splitting them would knowingly publish a false
no-background-work contract between merges.

The private implementation owns cancellable and reapable resolver and artifact
reader subprocesses, one long-lived pooled async HTTP client, reentrant logical
operations, and one close owner. Close rejects new logical operations, drains
admitted operations under their original deadlines, permits their internal
reconciliation requests, then closes transport and always stops/joins its loop.
Concurrent close callers await the same result. Linux uninterruptible `D`-state
remains the approved synchronous-owner physical exception.

This changes no public API, dependency, service, configuration, retry policy,
wire contract, or scope assigned to issues #34, #35, or #37. Acceptance remains
focused lifecycle/fault tests, the clean PostgreSQL 17 canonical gate, exact-
head CI, one normal automatic Codex review, and zero unresolved in-contract
threads. AO final review and merge remain controller-owned and out of scope.
